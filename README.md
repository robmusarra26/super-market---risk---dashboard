# Super Market Risk Dashboard

A simple browser dashboard for monitoring market regimes relevant to a diversified superannuation portfolio.

## Automatic data refresh
A GitHub Actions workflow refreshes the public FRED market/economic series on weekdays.

## Turn on GitHub Pages
Open **Settings → Pages** in this repository.
Under **Build and deployment**, choose **Deploy from a branch**.
Select **main** and **/(root)**, then Save.

The dashboard is a monitoring and education tool only; it is not personal financial advice or a buy/sell signal.
